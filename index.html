01 개인 평가 프로젝트

AI 응답 직접 평가

공개 개인 기록 · 2026.06

문제응답의 차이와 판단 근거를 어떻게 기록할 것인가?

경상도 사투리를 표준어로 풀이한 AI 답변을 읽고, 표현의 의미와 말투를 직접 평가했습니다.

그저께 / 며칠 전

개인 평가 기록 R008의 추가 설명에서 발췌했습니다. 응답에 제시된 의미 범위를 함께 살펴봅니다.

역할과 과정, 검토 결과
내 역할
질의응답과 최종 평가를 직접 수행하고 점수·판단 이유를 기록했습니다. 템플릿에 AI 지원을 사용했습니다.
과정
P008 요청 → R008 응답 → E008 당시 판단 → 해석 범위 유보
검토 내용
10개 프롬프트의 응답을 8개 기준으로 평가했습니다. 점수와 함께 출처·표현·불확실성에 대한 판단 근거를 기록했습니다.
한계
소규모 개인 프로젝트 기록입니다. 현재 모델의 일반 성능 순위로 확장하지 않습니다.

02 개인 QA 프로젝트

웹 QA와 회귀 테스트

공개 개인 기록 · 2026.06

문제주요 기능은 어떤 조건에서 기대한 대로 동작하는가?

역할과 과정, 검토 결과
내 역할
요구사항·화면·문구를 검토하고, AI 지원 구현과 기초 자동 검사를 구분해 확인했습니다.
과정
페이지·조건 → 수동·정적 검토 → 기초 브라우저 확인 → 검증 범위 제한
검토 내용
개인 홈페이지의 기능과 링크, 화면 표시를 검토하고 Playwright로 주요 영역의 기본 회귀 테스트를 구성했습니다.
한계
수동·정적 검토와 기초 회귀의 범위입니다. 전체 품질 보증이나 고객사 실무 산출물이 아닙니다.
