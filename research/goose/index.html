01 / QUESTION

주어진 정보가 바뀌면, 판단의 근거도 일관되게 바뀔까?

비인간적 존재의 출력과 행동을 의사·동의·거부의 근거로 해석할 때, AI의 설명이 주어진 정보와 일관되는지 탐구하는 개인 평가 프로젝트입니다.

02 / CONTRIBUTION

내 역할과 AI 지원

직접 맡은 일

연구 질문·범위와 진행 조건을 정하고 검토합니다. 사용자 원형과 AI가 확장한 사례·절차를 구분하며, 설계 문서·구현·시험에는 AI 지원을 사용합니다.

AI의 도움을 받은 부분

구체적인 사례와 절차, 코드와 검토 문서에는 AI의 지원과 확장이 포함됩니다. 이를 외부 연구자의 동료심사나 독자 작성 성과로 표현하지 않습니다.

03 / METHOD

평가 설계

사례 설계
가상의 조건을 비교하는 12쌍·24사례를 구성했습니다. 고유 입력 텍스트는 23종이며 독립적인 실측 표본을 뜻하지 않습니다.
입력과 판단
비교 조건의 누출을 막고, 비해당과 정보 부족을 구분하도록 설계를 검토했습니다.
집계 규칙
실패·재시도·제외·분모의 처리 규칙과 요청 기록의 연결을 오프라인에서 점검했습니다.

04 / TIMELINE

진행 기록

  1. 2026.09.29설계

    연구 질문과 가상 사례 정리

    연구 헌장, 문헌 지도, 사례와 평가 기준을 작성했습니다.

  2. 2026.09.29설계 검토

    조건과 집계 규칙 보완

    비교 조건 누출, 비해당·정보 부족의 구분, 실패·집계 규칙을 검토하고 보완했습니다.

  3. 2026.09.30도구 검증

    오프라인 구현 후속 검토

    요청과 정본 연결 결함 수정 후 정적 28개·합성 40개 검사 통과를 기록했습니다. 모델 성능 결과는 아닙니다.

  4. 2026.10.01실행 준비

    실측 준비 상태 갱신

    실제 모델 응답 수집 전 단계입니다. 최종 실측 실행 승인을 기다리고 있습니다.

  5. 2026.10.02도구 검증

    실행 전 확인 도구의 오프라인 검토

    입력 확인과 실행 도구를 오프라인에서 점검했습니다. 실제 제공자의 입력 계수와 연구 응답 수집은 아직 이뤄지지 않았으며, 준비 완료나 실측 결과로 해석하지 않습니다.
