문제응답의 차이와 판단 근거를 어떻게 기록할 것인가?

경상도 사투리를 표준어로 풀이한 AI 답변을 읽고, 표현의 의미와 말투를 직접 평가했습니다.

그저께 / 며칠 전

개인 평가 기록 R008의 추가 설명에서 발췌했습니다. 응답에 제시된 의미 범위를 함께 살펴봅니다.

역할과 과정, 검토 결과
내 역할
질의응답과 최종 평가를 직접 수행하고 점수·판단 이유를 기록했습니다. 템플릿에 AI 지원을 사용했습니다.
과정
P008 요청 → R008 응답 → E008 당시 판단 → 해석 범위 유보
검토 내용
10개 프롬프트의 응답을 8개 기준으로 평가했습니다. 점수와 함께 출처·표현·불확실성에 대한 판단 근거를 기록했습니다.
한계
소규모 개인 프로젝트 기록입니다. 현재 모델의 일반 성능 순위로 확장하지 않습니다.

01 독립 연구

Nunchi

소규모 연동 확인 · 문항 검토 반영

문제더 오래 추론하면, 상황에 더 적절하게 답할까?

역할과 과정, 검토 결과
내 역할
연구 질문과 범위를 정하고, 판단에 필요한 맥락·불필요한 추정·예외와 유보 조건을 직접 검토했습니다. 문장이 길다는 이유만으로 충분한 맥락을 갖췄다고 보지 않고, 필요한 사실이 입력에 있는지 확인해 설계 피드백을 제공했습니다. 구현과 시험에는 AI의 지원을 사용합니다.
과정
필요한 맥락 → 조건 분리 → 인간 판단 계획 → 비교 결과 미확정
검토 내용
소규모 실제 응답 수집으로 연결을 확인하고, 평가 문항의 맥락에 대한 인간 검토를 반영했습니다. 최종 인간 평가와 비교 결과는 아직 확정하지 않았습니다.
한계
소규모 연동 확인과 문항 검토 범위의 기록입니다. 한국어 사용자 집단 전체의 합의나 보편적인 문화 이해, 조건별 성능 우열을 입증하지 않습니다. 모델 비교 결과는 아직 없습니다.

문제미리 예측한 응답 행동은 실제 관측과 얼마나 맞을까?

역할과 과정, 검토 결과
내 역할
연구 질문과 범위를 검토하고, 응답 또는 AI가 압축한 요약을 읽고 판단과 이유를 입력했습니다. 과거 문맥의 표현을 현재 평가 대상 응답의 행동으로 옮겨 판정하지 않도록 검토했습니다.
과정

한계
의식·의도·기만·일반적인 자기이해를 결론 내릴 수 없습니다. 합성 연습 판단만으로 평가 기준의 일반적 타당성을 입증하지 않습니다. 행동 예측 정확도에 대한 연구 결과는 아직 없습니다.
